# FinSoko Responsible Loan Assistant

An AI-powered web app that simulates a Scout Agent and Loan Triage Agent handoff for responsible microlending to informal traders in East Africa. It follows the RANK, TRAIL and PRIDE Loop frameworks and the Kenya Data Protection Act 2019, and was built as part of the AI Safari Capstone Project.

Live demo: https://finsoko-prototype.vercel.app

## Run it locally

npm install
npm run dev

Then open the link shown in the terminal.

## Build

npm run build
npm run preview
